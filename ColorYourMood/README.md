## لون مزاجك || Color Your Mood

صفحة ويب بسيطة وتفاعلية تتيح للمستخدم اختيار لونه المفضل وتغيير خلفية الشاشة مع رسائل عشوائية.  
A simple interactive web page that lets the user pick a favorite color, change the background, and receive a random mood message.

---

## المميزات | Features

- 🎨 **اختيار الألوان** — color picker مع معاينة فورية وكود HEX
- 🖱️ **زر تفاعلي** — لون الزر يتغير تلقائياً على حسب اللون المختار
- 🔆 **تباين تلقائي** — لون النص في الزر يتكيّف (أبيض أو داكن) حسب درجة إضاءة اللون
- 💬 **رسائل عشوائية** — تظهر واحدة من 3 عبارات بعد الضغط على الزر
- 🌐 **دعم اللغتين** — تبديل فوري بين العربي والإنجليزي مع دعم RTL/LTR

## كيفية الاستخدام | How to Use

1. افتح `index.html` في المتصفح  
   Open `index.html` in any browser

2. اختر لونك المفضل من الـ color picker  
   Pick your favorite color from the color picker

3. اضغط زر **تم** لتطبيق اللون  
   Click **Done** to apply the color

4. شاهد الرسالة العشوائية التي تظهر  
   See the random mood message appear

5. بدّل اللغة بالضغط على زر **EN / عربي**  
   Toggle language with the **EN / عربي** button
