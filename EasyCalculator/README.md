# EasyCalculator

A simple, clean calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Decimal point support
- Backspace (delete last character)
- Clear button to reset the display
- Responsive layout with a background image
- Dark-themed UI with hover effects

## Project Structure

```
EasyCalculator/
├── index.html           # Main HTML structure
├── style.css            # Styling and layout
├── script.js            # Calculator logic
└── imgForBackground.png # Background image
```

## How to Use

1. Open `index.html` in any modern web browser — no installation required.
2. Click the number and operator buttons to build an expression.
3. Press `=` to evaluate.
4. Press `C` to clear the display, or `⌫` to delete the last character.

## Technologies Used

- HTML5
- CSS3 (CSS Grid, Flexbox, background image)
- Vanilla JavaScript
